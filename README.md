# Adivasi Skills Platform

A modern, responsive web application for tribal youth skill development in Jharkhand, India.

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: Node.js + Express + TypeScript
- **Database**: PostgreSQL (Prisma ORM)
- **Features**: Skill‑based learning, AI career guide, portfolio builder, certificates, regional‑language support, admin dashboard.

---

## Project Structure
```
tribal-skills-platform/
├─ client/           # React frontend
├─ server/           # Express backend
├─ docker-compose.yml
└─ README.md
```

## Getting Started
```bash
# From the project root
docker-compose up --build
```

The frontend will be available at `http://localhost:5173` and the API at `http://localhost:4000`.
